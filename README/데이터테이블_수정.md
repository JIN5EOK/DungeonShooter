# 개요
- 기존에는 CSV 단독 구조로 관리하고 있었음
- 수치 편집 및 일괄편집에서는 데이터 테이블 관리가 이점이 있지만 게임오브젝트 및 에셋 할당에는 확실히 에셋기반이 훨씬 직관적이라고 판단

# 변경 방향
- 런타임엔 스크립터블 오브젝트 기반으로 동작, 하지만 에디터에서 간편하게 CSV <-> 스크립터블 오브젝트간 변환을 수행할 수 있도록 함

``` mermaid
classDiagram
    class Bar{
        +barA : int
        +barB : float
    }

    class Foo{
        <<ScriptableObject>>
        +id : int
        +intValue : int
        +intList : List~int~ 
        +bar : Bar
    }
    
    class SerializedFoo{
        +Id : int
        +IntValue : int
        +IntList : string // 문자열 기반으로 "9/25/10" 같이 한 열에 리스트 데이터를 담기
        +BarbarA : int
        +BarbarB : float
        +SerializedFoo(Foo foo) // 생성자, Foo로부터 데이터 생성
        +ApplyTo(Foo foo) void // Foo에 데이터 적용
    }

    class CSVSerializer{
        +CSVToSO~T~(string readPath, string writeFolder) bool
        +SOToCSV~T~(string readFolder, string writePath) bool
    }
    
    class DataSerializeHelper{
        +ListToString~T~(List~T~) : string
        +stringToList~T~(string text) : List~T~
        ... 그외 직렬화 관련  공통기능 추가 선언
    }
    Bar <-- Foo
    SoDataSerializerEditor --> CSVSerializer : SerializedFoo 전달 및 직렬화/역직렬화 요청
    SoDataSerializerEditor ..> SerializedFoo : Foo를 이용해 생성
    사용자 --> SoDataSerializerEditor : 에디터로 직렬화 / 역직렬화 요청
    Foo <.. SerializedFoo
    SerializedFoo --> DataSerializeHelper : 컬렉션 문자열화 등 필요한 공통로직 참조
```
- 위와 같이 직렬화 대상 스크립터블 오브젝트와 한쌍을 이루는 직렬화 전용 DTO 클래스 추가, 해당 클래스를 이용해 직렬화 혹은 역직렬화 수행
- 에디터에서 스크립터블 오브젝트를 직렬화하거나 역직렬화하는 기능 추가
